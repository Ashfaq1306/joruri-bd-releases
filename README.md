# Joruri BD — app downloads

**জরুরি বিডি** — Bangladesh emergency response app. *Help when every second matters.*

## Download (Android)

- **Most phones:** [joruri-bd.apk](https://github.com/Ashfaq1306/joruri-bd-releases/releases/latest/download/joruri-bd.apk)
- **Older 32-bit phones:** [joruri-bd-arm32.apk](https://github.com/Ashfaq1306/joruri-bd-releases/releases/latest/download/joruri-bd-arm32.apk)

Or visit **https://joruri-bd.web.app/download/**

Open the downloaded file and tap **Install** (allow "Install unknown apps" if asked).
The app tells you when a newer version is available.

This repository only holds the release files.
